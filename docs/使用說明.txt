春風陶笛

開啟「index.html」即可使用。建議使用新版 Chrome 或 Edge。
這是完整離線版，已包含 PDF.js；不需要 API 金鑰。所有樂譜留在本機瀏覽器。

1. 從「預設歌曲」選單選曲：望春風、小星星、歡樂頌、搖籃曲、平安夜、給愛麗絲〈主題段〉。切換會停止播放、更新簡譜並套用建議速度。預設仍為〈望春風〉；可暫停、循環與調整速度、音量。
2. 上方上傳 TXT / MusicXML，可載入樂譜並使用合成陶笛音色播放。
3. 「樂譜辨識・轉成數字簡譜」可設定 1 的音高，轉換或下載數字簡譜。
4. 同區域可上傳 PNG、JPG、WebP、PDF。選擇 PDF 頁碼與原譜調號，按「辨識這一頁」。
5. 對照圈選的音符與簡譜草稿，修正後按「確認草稿並載入播放器」。多頁樂譜可逐頁辨識，再按「將草稿接到目前樂曲後面」。

文字簡譜：空白分隔音符，1～7 為音階、0 為休止符，逗號降低八度、單引號提高八度；冒號後為拍數，例如 5,:1.5 5,:0.5 6, 1。

限制：
- 陶笛為 Web Audio 合成音色，非實體樂器錄音。圖案燈號非實際指法。
- MusicXML 讀第一聲部、第一聲線，取和弦的主音符，不展開反覆與裝飾音。變拍長可讀取，但播放速度依滑桿設定。
- 影像辨識是基礎輔助草稿，適合清晰、水平、印刷、單旋律高音五線譜，非完整專業 OMR。低音譜、多聲部、和弦、手寫譜與傾斜模糊照片不支援可靠辨識。
- 影像版實心音符暫設 1 拍、空心暫設 2 拍。附點、連桿節奏、休止符、臨時升降記號與反覆需人工校正；原譜調號由使用者指定。每次重辨識或點圖會重新產生草稿，請先保留手動修正內容。
- 影像每次辨識一頁，不會自動判定全曲節奏或保證正確率。
- PDF.js 5.4.624，Apache-2.0 授權；授權全文見 licenses/PDFJS-LICENSE.txt，程式保留內嵌授權標示。

已驗證：預設旋律 64 拍；播放／暫停；文字簡譜；MusicXML 音高、休止符、延音；合成掃描 PDF 的五線、8 個音符頭與轉換草稿。尚未以大量真實照片評估準確率。
